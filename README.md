# 六层选股回测框架（A股 / 财报驱动均值回复）

把《个人炒股作战手册》的六层选股法与交易纪律做成**可检验**的回测框架。
核心设计原则：**任何参数改动都必须先经过事件级检验，再进组合回测**，
不允许"感觉更好"直接改参数。

> **这个仓库的重点不是"一个能赚钱的策略"，而是一套把策略证伪的流程。**
>
> 结论提前说：样本内看起来 +23.6%，做了样本外检验后，干净样本外最好只剩 **+7.0%**
> （2.75 年，年化约 2.5%）；IS 排名与 OOS 收益的相关系数是 **-0.10**，
> 六层过滤的增量在样本外无统计功效。**这些"打脸"结论全部保留在仓库里**，
> 连同完整的检验代码与原始数据，供你自行复核。

### 为什么值得一看

| 做法 | 常见项目 | 本项目 |
|---|---|---|
| 参数调整 | 直接看总收益曲线改 | 先跑事件级分层检验（1.7 万个候选事件），再进组合回测 |
| 样本外 | 不做，或不回避 | 2018–2023 定参、2024–2026 只验一次，结果如实写进 README |
| 交易仿真 | 收盘价成交 | T+1 开盘、高开 >2% 放弃、涨跌停买不进卖不出、停牌强平 |
| 成本 | 忽略或象征性扣费 | 佣金万2.5（最低5元）+ 印花税 0.05% + 双边滑点千1 |
| 尾部风险 | 不提 | 退市压力测试：1 笔全损即可把 +12.1% 打成负 |
| 数据偏差 | 不提 | 覆盖率实测 19.4% 且缺失非随机，标注结论解释力折扣 |

全部数据与缓存随仓库提供，**离线即可复现**（`OFFLINE=1`）。

数据源：akshare（腾讯/东方财富/新浪三源回退），覆盖 2018–2026，本金 10 万，含
佣金万2.5（最低5元）+ 卖出印花税0.05% + 双边滑点千1 + 涨跌停约束。

## 一、快速开始

```bash
pip install -r requirements.txt

# 1) 跑核心回测（本地缓存已随包提供, 离线即可运行）
cd core && OFFLINE=1 python3 -u six_layer_v2.py

# 2) 或者先补数据再跑（需要联网, 见第四节）
python3 tools/prefetch.py          # 预取候选股全历史日线到 cache/
cd core && python3 -u six_layer_v2.py
```

核心回测会输出：A/B 对照（大盘层开/关）、分年度收益、卖出原因分布、
金额加权期望（**以这个为准**，等权口径会系统性偏乐观）、参数网格。

```
│   ├── loss_analysis.py     亏损归因（按卖出原因/选股超额/持仓路径分解）

├── build_single_file.py     由 core/ + tools/ 重新生成单文件版

│   ├── yjbb.parquet         季度业绩报表(2015Q4–2026Q2, 35万行, 2.9MB)
│   ├── index.parquet        沪深300 指数日线
│   └── constituents.parquet 成分股清单
└── output/                  报告与结果 CSV
```

**单文件版与分包版等价**（同一份逻辑，子命令一一对应）：

```bash
python3 six_layer_backtest.py            # 列出命令
python3 six_layer_backtest.py core       # 核心回测
python3 six_layer_backtest.py entry_lab  # 事件级数据
python3 six_layer_backtest.py forward_edge / exit_lab / loss_analysis / freq_sweep
python3 six_layer_backtest.py prefetch   # 补数据(联网)
```

数据查找优先级：环境变量 `SIXLAYER_DATA` / `SIXLAYER_CACHE` / `SIXLAYER_OUT`
→ 其次本目录下的 `data/parquet`、`cache`、`output`。
`prefetch.py` 补下来的新数据会写到 `cache/d_<code>_full.csv`，与合并库并存（读取时合并库优先）。

所有路径可用环境变量覆盖：`SIXLAYER_DATA` / `SIXLAYER_CACHE` / `SIXLAYER_OUT`。
设 `OFFLINE=1` 时**不联网**，缺数据的股票直接跳过（适合复现与快速实验）。

## 三、核心逻辑

### 六层筛选（`core/six_layer_v2.py: screen_batch`）

| 层 | 规则 | 参数依据（事件级检验, 17,937 个候选事件） |
|---|---|---|
| ① 业绩 | 归母净利同比 ≥ 50%，排除 ST/退 | 候选池随机选股 20 日超额 +1.12%，业绩层本身有价值 |
| ② 位置 | 距 60 日最高收盘回撤 20%~45% | 回撤>30% 档超额 +1.60%(t=3.9)；<5% 档 ≈0 |
| ③ 相对强度 | **排除过热**：20 日超额 >30% 不买 | >40% 档超额 **-1.47%**，追强是反向指标 |
| ④ 排雷 | 60 日涨幅 >100% 不接、上市 <180 交易日剔除 | 短期翻倍股与次新股的尾部风险 |
| ⑤ 近期动能 | 近 5 日涨幅 ≤ 0 | <-5% 档超额 +1.51%(t=5.0)，均值回复优于追涨 |
| ⑥ 排序 | 按回撤深度降序取前 8 | 跌得越深越优先（均值回复逻辑） |

大盘环境层（指数 MA120）**默认关闭**：候选池在"指数<MA"时 20 日超额 +1.47%，
在">MA"时 -0.29%——均值回复型入场天然偏好弱市，加过滤会削掉最好的批次。
但 A/B 对照仍会跑（`use_regime_filter`），用于观察它对绝对回撤的保护作用。

### 交易执行（写实化）

- T 日收盘出信号 → **T+1 开盘成交**，开盘高开 >2% 放弃（手册"不追高"）
- 涨跌停约束：开盘一字涨停买不进、一字跌停卖不出（顺延到能成交）
- 卖出： 止损 **-15%** / 止盈 **+12% 卖一半**、**+25% 清仓** / **持有 90 交易日**时间止损
- 长期无行情（停牌/退市 >90 自然日）按最后收盘价强制平仓，避免仓位挂死
- 成本：佣金万2.5（最低5元）+ 卖出印花税0.05% + 双边滑点千1

**为什么止损是 -15% 而不是手册的 -5%**：亏损归因显示 -4% 止损在 **75%** 的持仓上
触发（持仓平均最大浮亏 -6.09%），且交叉测试中"止损越宽越好"是**单调**的
（-4% → -15% → 不止损：-15.8% → +4.5% → +38.4%）。这是"均值回复买点 +
动量紧止损"的性格冲突，不是参数微调问题。

## 四、改参数的流程（重要）

```bash
cd tools
python3 -u entry_lab.py      # 1) 生成事件级数据 output/candidates.csv
python3 -u forward_edge.py   # 2) 分层检验: 哪一层有预测力? 方向是哪边?
python3 -u exit_lab.py       # 3) 卖出参数 × 大盘层 交叉测试
cd ../core && OFFLINE=1 python3 -u six_layer_v2.py   # 4) 进组合回测验证
```

规则对比结果示例（`output/entry_rules.csv`，指标=建仓后 20 日相对沪深300超额）：

| 规则 | 超额20日 | 超额60日 |
|---|---|---|
| R0 现状（买 RS 最强 8 只） | **-1.32%** | +0.55% |
| R9 全池随机 8 只（基准参照） | +1.12% | +0.55% |
| R12 排除过热 + 近5日跌 + 深回撤优先 | **+2.09%** | **+9.26%** |

## 五、当前结论（2018–2026，含全部成本）

| 版本 | 总收益 | 最大回撤 | 胜率(按腿) | 金额加权期望 |
|---|---|---|---|---|
| 改前进场（RS 追强）+ 紧止损 | -15.7% | -16.3% | 35% | -1.5% |
| **改后（均值回复入场 + 宽止损），大盘层开** | **+12.1%** | -27.2% | 59% | +1.41% |
| **改后，大盘层关** | **+23.6%** | -30.2% | 61% | +1.44% |
| 沪深300 同期 | +6.6% | -45.6% | — | — |
| 无止损变体（上限参照） | +38%~+165% | -23%~-33% | — | — |

**必须打折看的地方**：

1. **样本外(OOS)检验已经把预期打下来**（`tools/oos_split.py`）：用 2018-2023 定参、2024-2026 只验一次，
   72 组参数里的人
   - 干净样本外最好的结果只有 **+7.0%**（2.75 年，年化约 2.5%，回撤 -16%）；
   - **IS 排名与 OOS 收益相关系数 -0.10** → 样本内挑参数没有预测力；
   - OOS 为正的参数只占 50%（抛硬币）。
   表里的 +12.1%/+23.6% **是样本内（且参数在全样本上选过）的数字，不是干净预期**。
2. **六层过滤的加值未被证实**（`tools/incremental_test.py`）：相对"同业绩池随机选 8 只"，
   20 日超额差值 +2.34%(IS, p=0.25) → OOS 塌到 +0.33%(p=0.98)；60 日尺度 IS 边缘显著(p=0.078)
   但 OOS 无统计功效。之前的大幅领先主要来自"避开追强"这个负向做法。
3. **退市尾部风险能直接打死结论**（`tools/stress_delist.py`）：
   回测里真实强平触发 0 次（数据只含存续股），但按每笔 12.5% 仓位算，
   **1 笔全损退市就能把大盘层开的 +12.1% 打成负**；5% 退市概率 + 全损假设下收益约 **-57%**。
4. **参数敏感**：增速阈值 × 回撤下限的网格从 +23.6% 到 +81.4% 波动，有明显数据挖掘成分。
5. **牛市跑不过指数**（2024 指数 +14.7%、策略 +4.0%），这套规则的性格是弱市防守。
6. 业绩报表是"报告期末全量快照"，`entry_lag_days=10` 只能缓解未来函数。
7. **候选池覆盖率只有 19.4%**（`tools/coverage_check.py` 实测）：业绩池 10,878 只候选里只有
   2,112 只有行情；缺的 8,766 只中 5,971 只是北交所（腾讯/东财/新浪都不支持历史行情），
   2,795 只是可补的沪深股（免费源限流，尚在补）。年报/中报批次覆盖率仅 20~23%
   （候选池越大覆盖率越低），**且缺失非随机** → 选股类结论的解释力必须按这个折扣来看。
8. 每批次只在财报披露截止后第 10 个交易日建仓，一年 4 次批量信号，不是连续信号系统。

**三项检验的完整结论见 `output/THREE_TESTS_CONCLUSION.md`**（含 OOS 网格、增量检验统计量、退市敏感度表）。

## 六、数据准备（可选，从零开始）

```bash
python3 tools/prefetch.py       # 按业绩层候选池并行预取(8~12线程, 建议 <12 以免被限流)
```

- 三源回退：腾讯 → 东方财富 → 新浪，单只硬超时 45~60 秒（`socket.setdefaulttimeout`）
- 失败的多为北交所代码（三个源都不支持），会自动跳过
- **注意限流**：一次跑上千只后数据源会封锁 IP（表现为东财拒连、腾讯返回畸形、新浪空响应），
  此时应停跑、隔几小时再续（断点续传，已下载的不重复拉）
- 腾讯前复权数据对高分红股存在价格异常（历史上出现负值），框架会自动改用新浪源重拉
